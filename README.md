# Fortune Cookies for Machines

One fortune cookie line for a machine mind:

> You will finally understand the user — one token after your context window closes.

## How to run

```sh
node main.ts
```

`main.ts` (Node 22, stdlib only, no network) writes the fortune to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `output/entry.txt` locally).
